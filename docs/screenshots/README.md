# Скриншоты

Скриншоты интерфейса ClipForge с демонстрационными ответами API. Монтажный план задан вручную, ролики собраны через `media.RenderMontage`.

Видеоматериал — трейлер **Sintel**, © copyright Blender Foundation | [durian.blender.org](https://durian.blender.org/). Лицензия [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/), [условия проекта](https://durian.blender.org/sharing/). Источник: [копия трейлера на W3C](https://media.w3.org/2010/05/sintel/trailer.mp4). Для примера исходник обрезан до вертикального кадра, затем выбранные отрывки склеены в три варианта.

Референс компоновки — [редактор Descript](https://www.descript.com/blog/article/descript-tutorial-for-beginners-6-steps-to-get-started): файловая панель и компактная рабочая область.
