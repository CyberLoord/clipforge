# HTTP API

JSON использует секунды для времени и RFC 3339 для дат. Ошибки имеют вид `{"error":"message"}`.

| Метод | Путь | Результат |
| --- | --- | --- |
| GET | `/healthz` | Готовность приложения и PostgreSQL |
| GET | `/api/config` | Режим и лимиты |
| GET | `/api/jobs` | Последние 100 заданий, новые первыми |
| POST | `/api/jobs` | Загрузка и постановка в очередь, `202` |
| GET | `/api/jobs/{id}` | Состояние, расшифровка и клипы |
| POST | `/api/jobs/{id}/cancel` | Отмена queued/running задания |
| POST | `/api/jobs/{id}/retry` | Повтор failed/cancelled задания с сохранённого этапа |
| POST | `/api/jobs/{id}/reprocess` | Новая нарезка сохранённого исходника, `202` |
| PATCH | `/api/jobs/{id}/clips/{clipId}` | Изменение границ и повторный экспорт, `202` |
| GET | `/api/jobs/{id}/clips/{clipId}/video` | MP4 с поддержкой Range |

## Загрузка

```sh
curl -F 'mode=montage' -F 'file=@sample.mp4' http://localhost:8080/api/jobs
```

Необязательное поле `mode` (`montage`, `split`, `openai`, `demo`) должно идти перед единственным полем `file`. Без него используется режим сервера, по умолчанию `montage`. Доступные режимы и раздельные лимиты исходника и клипов возвращает `/api/config`. Для `montage` и `openai` требуется настроенный ключ.

Исходник — от 15 секунд, по умолчанию до 30 минут и 300 МиБ. Проверка размера и контейнера выполняется при загрузке; длительность и дорожки проверяются воркером. Поэтому принятый запрос ещё не означает, что видео пригодно для обработки.

## Задание

Поля: `id`, `filename`, `status`, `stage`, `mode`, `duration`, `error`, `attempts`, `created_at`, `updated_at`, `transcript`, `clips`.

Статусы: `queued`, `running`, `completed`, `failed`, `cancelled`. Этапы: `probe`, `transcribe`, `select`, `render`, `completed`. `attempts` относится к текущему этапу. При ожидающем повторе `error` содержит причину последней неудачи.

Сегмент расшифровки: `{"start":0,"end":5,"text":"Текст"}`.

В режимах `split` и `montage` этап `transcribe` пропускается, расшифровка остаётся пустой. В `montage` этап `select` включает получение кадров и их анализ.

Клип содержит `id`, `start`, `end`, `title`, `reason`, `revision` и `path`. Непустой `path` означает наличие опубликованного файла; получать его следует через endpoint `/video`.

В `montage` результат дополнительно содержит `style` (`dynamic`, `cinematic`, `story`) и `cuts`: массив `{"start":1,"end":3}` в порядке монтажа. Для этих результатов `start` и `end` равны нулю: длина готового ролика равна сумме длин `cuts`. Один вариант содержит 2–12 сцен по 1–15 секунд, занимает 5–60 секунд и использует не более 85% исходника. Сцены внутри варианта не повторяются. Вариантов — два или три.

## Повторный экспорт

```sh
curl -X PATCH http://localhost:8080/api/jobs/JOB_ID/clips/CLIP_ID \
  -H 'Content-Type: application/json' \
  -d '{"start":5,"end":35}'
```

Доступен для завершённого задания с одиночными фрагментами. Для `montage` возвращает `409`: один диапазон не описывает монтаж нескольких сцен. Интервал должен находиться внутри исходного видео и длиться от 5 до 60 секунд. Пересечение с другим клипом не должно превышать половину меньшего интервала. Новая ревизия сохраняет название и объяснение исходного выбора.

## Новая нарезка

```sh
curl -X POST http://localhost:8080/api/jobs/JOB_ID/reprocess \
  -H 'Content-Type: application/json' \
  -d '{"mode":"montage"}'
```

Доступна для `completed`, `failed` и `cancelled`. Сохраняет исходник, очищает текущую расшифровку и список клипов, запускает обработку с `probe` в выбранном режиме.

Для скачивания добавить `?download=1` к `/video`.

Коды ошибок: `400` — параметры, `404` — задание или клип не найден, `409` — неподходящее состояние или пересечение, `413` — размер, `415` — формат, `503` — режим AI не настроен. `500` не раскрывает внутреннюю ошибку; подробности остаются в структурированном логе сервера.
