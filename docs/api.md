# HTTP API

JSON использует секунды для времени и RFC 3339 для дат. Ошибки имеют вид `{"error":"message"}`.

| Метод | Путь | Результат |
| --- | --- | --- |
| GET | `/healthz` | Готовность приложения и PostgreSQL |
| GET | `/api/config` | Режим и лимиты |
| GET | `/api/jobs` | Последние 100 заданий, новые первыми |
| POST | `/api/jobs` | Загрузка и постановка в очередь, `202` |
| GET | `/api/jobs/{id}` | Состояние, расшифровка и клипы |
| POST | `/api/jobs/{id}/cancel` | Отмена queued/running задания |
| POST | `/api/jobs/{id}/retry` | Повтор failed/cancelled задания с сохранённого этапа |
| PATCH | `/api/jobs/{id}/clips/{clipId}` | Изменение границ и повторный экспорт, `202` |
| GET | `/api/jobs/{id}/clips/{clipId}/video` | MP4 с поддержкой Range |

## Загрузка

```sh
curl -F 'file=@sample.mp4' http://localhost:8080/api/jobs
```

Ровно одно поле `file`. По умолчанию до 300 МиБ. Проверка размера и контейнера выполняется при загрузке; длительность и дорожки проверяются воркером. Поэтому принятый запрос ещё не означает, что видео пригодно для обработки.

## Задание

Поля: `id`, `filename`, `status`, `stage`, `mode`, `duration`, `error`, `attempts`, `created_at`, `updated_at`, `transcript`, `clips`.

Статусы: `queued`, `running`, `completed`, `failed`, `cancelled`. Этапы: `probe`, `transcribe`, `select`, `render`, `completed`. `attempts` относится к текущему этапу. При ожидающем повторе `error` содержит причину последней неудачи.

Сегмент расшифровки: `{"start":0,"end":5,"text":"Текст"}`.

Клип содержит `id`, `start`, `end`, `title`, `reason`, `revision` и `path`. Непустой `path` означает наличие опубликованного файла; получать его следует через endpoint `/video`.

## Повторный экспорт

```sh
curl -X PATCH http://localhost:8080/api/jobs/JOB_ID/clips/CLIP_ID \
  -H 'Content-Type: application/json' \
  -d '{"start":5,"end":35}'
```

Доступен для завершённого задания. Интервал должен находиться внутри исходного видео и длиться от 15 до 60 секунд. Пересечение с другим клипом не должно превышать половину меньшего интервала. Новая ревизия сохраняет название и объяснение исходного выбора.

Для скачивания добавить `?download=1` к `/video`.

Коды ошибок: `400` — параметры, `404` — задание или клип не найден, `409` — неподходящее состояние или пересечение, `413` — размер, `415` — формат. `500` не раскрывает внутреннюю ошибку; подробности остаются в структурированном логе сервера.
